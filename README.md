## 설치 방법

[최신 릴리스](https://github.com/AndyH0ng/minecraft-galmuri/releases/latest)에서 리소스팩 ZIP을 받아 `resourcepacks`에 넣고 활성화하세요.

OS 별 디렉토리는 아래를 참조

### Windows
```
%APPDATA%\.minecraft\resourcepacks
```

### Mac
```
~/Library/Application Support/minecraft/resourcepacks
```

### Linux
```
~/.minecraft/resourcepacks
```


## 볼드 겹침 보정 (선택)

26.3 + Fabric에서 볼드가 이중으로 보이면 [Galmuri Bold Fix](mods/galmuri-bold-fix/README.md)를 함께 사용할 수 있습니다. 원본 갈무리 TTF는 유지하며 볼드 간격만 0.5픽셀로 줄입니다. 모드 설치·교체 후에는 게임 재시작이 필요합니다.
