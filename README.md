# minecraft-galmuri

마인크래프트의 한글 서체를 갈무리-9로 교체하는 리소스팩입니다.

<img width="966" alt="sample" src="https://github.com/user-attachments/assets/873041a4-48a5-4f91-87d7-fbe94ce20cae" />


## 설치 방법

`resourcepacks` 에 폴더를 위치시킨 후 리소스팩을 활성화하세요.

OS 별 디렉토리는 아래를 참조

### Windows
```
%APPDATA%\.minecraft\resourcepacks
```

### Mac
```
~/Library/Application Support/minecraft/resourcepacks
```

### Linux
```
~/.minecraft/resourcepacks
```


## 호환성

리소스팩 메타데이터는 기존 형식 8 지원을 유지하면서 26.3(97.1) 및 26.4 Snapshot 6(101.0)의 `min_format`·`max_format` 선언을 포함합니다. 게임 내 확인은 26.3에서 진행했습니다. 폰트 파일, 크기, 오버샘플링은 변경하지 않았습니다.

## 볼드 겹침 보정 (선택)

26.3 + Fabric에서 볼드가 이중으로 보이면 [Galmuri Bold Fix](mods/galmuri-bold-fix/README.md)를 함께 사용할 수 있습니다. 원본 갈무리 TTF는 유지하며 볼드 간격만 0.5픽셀로 줄입니다. 모드 설치·교체 후에는 게임 재시작이 필요합니다.
